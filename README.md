# Mystery Club — интерактивная платформа расследований

Отдельный проект для каталога и прохождения интерактивных детективных квестов.

## Текущий этап
- Главная страница-каталог.
- Карточка первого расследования «Архив Вейл».
- Визуальная основа платформы.

## Важное разделение проектов
- `study-bloom` — отдельный учебный проект.
- `case-001` — оригинальный сайт первого квеста; его не изменяем.
- `mystery-platform` — новая платформа и отдельная онлайн-версия квестов.

## План разработки
1. Создать структуру каталога квестов.
2. Разработать универсальный игровой интерфейс: материалы, этапы, ответы и подсказки.
3. Перенести «Архив Вейл», сохранив сюжет и последовательность улик.
4. Добавить интерактивные формы первого и финального заключения.
5. Подготовить формат, позволяющий добавлять новые квесты без переписывания платформы.

## Публикация
Проект можно развернуть через GitHub Pages. Для этого в настройках репозитория нужно выбрать ветку `main` и папку `/ (root)` в разделе Pages.
